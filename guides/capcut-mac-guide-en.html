How to Import .CUBE LUTs in CapCut Desktop on Mac and Windows

English 日本語 Deutsch Français Italiano

CapCut features differ across operating systems, account tiers and app versions. Some Mac users report that the LUT import button is absent. Do not assume a pack will import before verifying your version.

Step-by-step workflow

  1. Open CapCut Desktop and identify its exact version and whether you are using Mac or Windows.
  2. Create a small test project and add a normal video clip to the timeline. Select the clip and inspect Adjustments / Color for any LUT feature or import control.
  3. If an Import or plus button exists, choose a small compatible .cube test LUT. Save the file outside a cloud-only placeholder folder so it is locally accessible.
  4. Apply the imported LUT gently and compare the original and result. Check skin tones, highlights and whether the project is Rec.709 or Log.
  5. If there is no LUT import button, do not force a .cube into the media browser. Check the latest official CapCut documentation and version-specific release notes, or use an editor confirmed to support .cube imports.

Common problems

No plus button? It may be a version/platform limitation, not a broken LUT. A .cube file is a color-lookup table, not a video or image file for ordinary Media import.

Before buying a LUT or preset

Confirm LUT-import support on your actual Mac/Windows build and the required source color space before buying any pack.
