How to Install .CUBE LUTs in DaVinci Resolve

English 日本語 Deutsch Français Italiano

Use a compatible .cube LUT in DaVinci Resolve, and check your project color management before applying creative looks.

Step-by-step

  1. Download a .cube LUT and extract it from its ZIP archive. Keep the file in an easy-to-find folder.
  2. Open DaVinci Resolve. Depending on the version, go to Project Settings > Color Management and use Open LUT Folder, or set a custom LUT Location in Preferences.
  3. Copy the .cube file into the LUT folder. Update the LUT list in Project Settings, or refresh the LUT list from the Color page as appropriate for your version.
  4. Open the Color page and find the imported LUT in the LUTs browser. Apply it to a suitable node; use a separate node for exposure/white balance corrections where practical.
  5. Check whether your footage is already Rec.709 or recorded as Log. Do not assume every creative LUT includes Log-to-Rec.709 conversion. Compare the result on scopes and export a short test clip.

Troubleshooting

If the LUT is missing, refresh the LUT list, check the folder path and the file extension. If the image looks extreme, verify color management and whether a technical transform has already been applied.

Source: Official Blackmagic Design DaVinci Resolve documentation. Interface labels can change between versions.
