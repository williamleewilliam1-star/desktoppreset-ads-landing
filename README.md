# DesktopPreset ChatGPT Ads landing page

A public, crawler-accessible product guide for DesktopPreset. Checkout remains on Etsy.

- Uses only existing DesktopPreset Etsy product imagery.
- No checkout or personal data collection.
- Preserves ad campaign/ad IDs as UTM parameters on outbound Etsy links.
- Explicitly allows OAI-AdsBot and OAI-SearchBot.
